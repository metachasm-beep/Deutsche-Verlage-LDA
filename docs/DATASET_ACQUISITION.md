## 🏛️ 2. Why Combine Deutsche Nationalbibliothek (DNB), Gemeinsamer Bibliotheksverbund (GBV / K10plus), HathiTrust HTRC, and OpenAlex?

1. **Exhaustive DNB SRU v1.1 MARC21 & Uncapped `location=onlinefree` + `MARC 856 $u` Multi-URL Harvesting (`1970–2025`):** In [`scripts/dnb_harvester.py`](file:///f:/PhD%20AG/scripts/dnb_harvester.py), we query DNB's electronic open-access location index (`location=onlinefree`) uncapped (`max_cap=10,000`, `--max-oa-books 100000`) across all 3-digit `DDC-Hauptsachgruppen` (`hsg=200`, `hsg=220`, `hsg=230`, `hsg=290`, `hsg=100`, `hsg=150`, `hsg=300`, `hsg=000/800/900`) sliced year-by-year (`jhr=1970..2025`), all 57 thematic/DDC CQL queries (`dcs=220*..290*` and `sw=`), and all 38 target German publishers (`vlg=`). For every `location=onlinefree` record, [`stream_dnb_oa_multi_url_in_ram`](file:///f:/PhD%20AG/scripts/dnb_harvester.py#L422-L441) cascades across `https://d-nb.info/{idn}/34`, sibling `MARC 856 $u` direct repository/publisher links, and `MARC 024` `nbn-resolving.org/urn:nbn:de:...` / `doi.org/...` persistent identifiers (including scraping `<meta name="citation_pdf_url">` and repository bitstream PDF links up to `90 MB` per monograph). This eleven-wave architecture extracts **`8,553` DNB open-access full-text books and EPUBs (`115,002` passages, `111.88M` words)**, **`2,394` DNB-matched HathiTrust printed books (`147,410` passages)**, **`32,035` digitized DNB `/04` `Inhaltsverzeichnis` & reading-sample PDFs/HTMLs**, and **`47,083` DNB `deposit.dnb.de` & `/blurb/` `Inhaltstexte`**, while exporting the complete work-level catalog in [`data/primary_texts/DNB_FULLTEXT_MASTER_MANIFEST.csv`](file:///f:/PhD%20AG/data/primary_texts/DNB_FULLTEXT_MASTER_MANIFEST.csv) (`82,283` unique works) and [`data/primary_texts/DNB_OPEN_ACCESS_FULLBOOKS_INVENTORY.csv`](file:///f:/PhD%20AG/data/primary_texts/DNB_OPEN_ACCESS_FULLBOOKS_INVENTORY.csv) (`12,739` complete full-text books).
2. **Complete GBV / K10plus SRU Harvesting Across 41 BKL Subcodes (`maximumRecords=100`):** In [`scripts/hathitrust_fullbook_harvester.py`](file:///f:/PhD%20AG/scripts/hathitrust_fullbook_harvester.py), we query **41 fine-grained `Basisklassifikation` subcodes (`11.00–11.99`, `08.36–08.44`, `71.00–71.50`)** across all 38 German publishers (`1,053` SRU pages at `maximumRecords=100`), extracting all `MARC 020` (`$a`, `$z`, `$9`) edition/print/online ISBNs (`56,241` multi-ISBN candidates) plus `17,458` direct GBV Open-Access PDFs (`gbv_kostenfrei_fullbook_pdf`), consortial TOC PDFs/blurbs (`gbv_direct_fulltext_pdf`), and `MARC 520` / `BKL` / `GND` enriched works (`drm_fallback_multi_api_enriched`).
3. **Full-Book Extraction for In-Copyright Printed Books (`1970–2025`) via HathiTrust HTRC EF 2.0 (§ 60d UrhG):** By cross-walking all GBV K10plus and DNB multi-ISBNs (`ISBN-10` and `ISBN-13` variants across `$a/$z/$9`) against the **HathiTrust Bibliographic API** and **HTRC Extracted Features v2.0 API**, our harvesters stream complete page-level POS-tagged token sequences for **4,031 printed German books (`243,751` passages, `243.16M` words)** in full compliance with German scientific Text and Data Mining law (**§ 60d UrhG**, *Abgeleitete Textformate*).
4. **OpenAlex Reconstructed `abstract_inverted_index` & OA Monograph Streaming (`1970–2025`):** Querying `api.openalex.org/works` (`per-page=200`, `has_abstract:true` and `is_oa:true`) reconstructs `627` German scholarly abstracts directly from `abstract_inverted_index` (`primary_cloud_oa_abstract`) and streams Open-Access German PDFs in RAM (`entire_fulltext_book_cloud` / `primary_cloud_oa_fulltext`).
5. **FAIR / DDI Preprocessing & Metadata Separation Protocol (Santana et al., 2025; Jiménez-Badillo et al., 2020):** Following Santana, Vasques Filho, Bojanowski, & Błoch (2025, *DHQ* 19.2 [`000788.html`](https://dhq.digitalhumanities.org/vol/19/2/000788/000788.html), §55–81), primary `text` fields exclude synthetic `{author}. {publisher}.` metadata headers, [`strip_archival_headers_from_text`](file:///f:/PhD%20AG/lda_pipeline.py#L722-L739) and [`clean_row_tokens_for_modeling`](file:///f:/PhD%20AG/lda_pipeline.py#L793-L826) strip bracketed provenance tags and deduplicate continuation-chunk book titles, and [`extract_row_metadata_tokens`](file:///f:/PhD%20AG/lda_pipeline.py#L778-L790) dynamically strips row-level author/publisher/imprint tokens while preserving [`CANONICAL_THEO_PHIL_WHITELIST`](file:///f:/PhD%20AG/lda_pipeline.py#L137-L146) across LDA, Quanteda/STM, and BERTopic.

## 🛠️ 3. Automated Harvesting & Analytical Execution Suite

```powershell
# 1. Run the Exhaustive Wave-11 DNB Harvester (location=onlinefree + MARC 856 + hsg= 1970-2025, exports DNB_FULLTEXT_MASTER_MANIFEST.csv)
python scripts/dnb_harvester.py --workers 48 --max-oa-books 100000

# 2. Run the Complete GBV/K10plus + HTRC Multi-ISBN + OpenAlex Harvester (auto-shards <88 MB across 20 shards)
python scripts/hathitrust_fullbook_harvester.py --workers 12

# 3. Run the 12-Topic Gensim LDA Pipeline across all 461,785 documents (exports app/lda_topics_report.json)
python lda_pipeline.py

# 4. Run the Quanteda + STM Analytics Suite (Komposita-Zerlegung, Dunning's G², OLS STM Regressions)
python scripts/quanteda_stm_analytics.py

# 5. Run the Neural Contextual Embedding + c-TF-IDF (BERTopic) Pipeline
python scripts/bertopic_german_pipeline.py
```
